# Letter Connectivity Layer

The orchestrator treats the Hebrew 22-letter set as a typed connectivity graph,
not merely as a list from which combinations are generated.

Layers:
1. Adjacency: ordered 22-letter backbone.
2. Final-form state: transition attached to the five relevant base letters;
   final glyphs remain outside the 22-node base alphabet.
3. Numeric equivalence: research-bundle relations such as י↔ס and ק↔ל.
4. Mirror/cross-pair candidates: supplied pairings such as א↔פ and ה↔ק.
5. Filling and filling-of-filling: reserved typed relations for the next layer.

Boundary:
The graph is a computational representation of symbolic relationships. It is
not a biological neural network and does not establish that the historical text
itself describes modern neural computation. Research-bundle relationships are
tagged SOURCE_CLAIM until checked against the source edition/page.
